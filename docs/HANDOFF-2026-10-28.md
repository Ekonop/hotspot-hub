# Handoff — Hotspot Hub on CachyOS (KIIT-WIFI-DU)

**Date:** 2026-10-28
**Machine:** CachyHP (CachyOS / Arch-based), KDE Plasma Wayland
**Wi-Fi:** MediaTek MT7922 (driver `mt7921e`), single radio
**Repo:** `~/Projects/hotspot-hub` (branch `main`, remote `origin/main` → `Ekonop/hotspot-hub`)
**Release:** `v0.6.1` published to GitHub (source tag + AppImage asset)

---

## 1. Original goal
Diagnose "limited connectivity" on KIIT-WIFI-DU (WPA2-Enterprise 802.1X, Aruba ClearPass) and replicate the Windows "it just works" behavior, shipping every fix into the **hotspot-hub** project and verifying on the live system.

**Root cause found:** the hotspot `ap0` was pinned to 5 GHz channel 36 while KIIT APs are on 2.4 GHz ch 1/6/11 (and weak 5 GHz 100/132). Single radio ⇒ AP and STA must share a channel ⇒ on-channel conflict. EAP auth itself actually succeeded.

## 2. Fixes shipped (all in `v0.6.1`)

| Area | Change | Files |
|------|--------|-------|
| Wi-Fi power-save off | `wifi.powersave = 2` global + per-profile `802-11-wireless.powersave 2` on `Hotspot-Shared` | `src/99-hotspot-powersave.conf`, `scripts/setup-profile.sh`, `install.sh`, `uninstall.sh`, `packaging/arch/PKGBUILD` |
| 2.4 GHz band policy | Pin STA to `band=bg` (and auto-reconnect if on 5 GHz) when SSID ∈ `BAND_POLICY_SSIDS` (default `KIIT-WIFI-DU`) | `src/hotspot-channelsync.sh` (deployed `/usr/local/bin/hotspot-channelsync.sh` + systemd service) |
| **Clients crash (SIGABRT)** | `_load_oui_vendors()` is underscore-private, skipped by `from core.services import *` → `NameError` inside the Qt event loop aborted the app whenever Clients was opened with stations present. Added explicit import. | `app/hotspot-hub.py` |
| **False "Degraded" on ICMP-block nets** | `health_check()` / `check_connectivity()` treat a failed gateway *ping* as inconclusive, falling back to DNS + TCP probes (`1.1.1.1:443`, `8.8.8.8:53`, OpenDNS:443). New `gateway_probe` field (`ok`/`icmp-blocked`/`tcp-only`). Stops smart-reconnect firing needlessly on KIIT. | `core/services.py`, `cli/hotspot-hub-cli.py` (metric help) |
| **Packaging crash on launch** | App does `from core.config import *` but `core/` wasn't shipped → `ModuleNotFoundError`. Now ships `core/`+`cli/` under `/usr/share/hotspot-hub/` and installs a launcher shim at `/usr/bin/hotspot-hub`. | `install.sh`, `packaging/arch/PKGBUILD` |
| CLI band-label bug | `status` previously printed the config *preference* next to the live channel (e.g. `Channel=36 (Band: 2.4GHz)`); now derives the actual band from the channel number, preference shown only when non-Auto. | `cli/hotspot-hub-cli.py` |

**Commits:** `8a5506b` (crash + connectivity + packaging), `c62c546` (CLI band), `d067e5a` (release v0.6.1 bump).

## 4. Known open items / caveats

1. **AppImage GUI untested on a real display.** The artifact is a valid type2 AppImage (smoke-tested `--appimage-version`), but the bundled Python/Qt UI was **not** launched/visually confirmed on this machine. Run `packaging/appimage/HotspotHub-0.6.1-x86_64.AppImage` to confirm the tray/window opens before advertising the binary.
2. **`_dns_resolves()`/`getent` is slow sometimes** (5 s timeout when the resolver stalls). Accepted — network is marked reachable via the separate `tcp-only` path, so a slow DNS never causes a false "Degraded".
3. **Duplicate private state (code smell, no crash):** `_RECONNECT_STATE`, `_RUN_CACHE`, `_RUN_RC_CACHE`, `_MUTATING_KEYWORDS` are redefined *both* in `app/hotspot-hub.py` and `core/services.py`. The app's copies shadow core's (not exported by `import *`); functional but fragile — `app/_RECONNECT_STATE` and `core/_RECONNECT_STATE` can drift. Consider deduping.
4. **`docs/HANDOFF-2026-10-28.md` (this file) is uncommitted** and intentionally not part of the release — commit or delete as you wish.
5. **Release is a source binary upload only** — the GitHub Actions CI is lint/test only (no release build). The AppImage was built manually.

```bash
# channel-sync log
journalctl -f -t hotspot-channelsync
# live status / band

# tests + lint
python3 -m unittest discover -s tests; ruff check app/ cli/ core/ tests/
```
